Freelancers live in chat, but invoicing still means dashboards and forms. What if billing were just a message?

[0:14.5–0:29.5] App home at localhost:8787 with the header status highlighted
ENSIDEX Invoice Agent is an AI chat agent built on the PayPal developer platform. In this recording, the AI runs live on OpenRouter, and PayPal runs in the app's built-in mock mode, exactly as the header shows.

[0:29.5–0:46.5] English invoice
One sentence. The agent picks the client, the amount and the purpose, turns "Friday" into a real date, and calls its create-invoice tool. With sandbox credentials set, that tool creates and sends a PayPal invoice through the Invoicing API.

[0:46.5–0:59] Arabic invoice (RTL)
It works in Arabic too. Riyals, Thursday, and the reply comes back in Arabic, right to left. Thursday becomes November fifth, and the currency is set to Saudi riyals.

[0:59–1:09.5] Payment link
Need a one-off payment? The payment-link tool uses the PayPal Orders API to return a checkout link, right in the same chat.

[1:09.5–1:31] Unpaid summary and reminder
Ask for a summary, and the AI reads your invoices, lists what's outstanding, and flags what's overdue. Here, Omar's invoice from October is flagged.
One more message, and the agent calls its reminder tool for that invoice.

[1:31–1:49.5] Code (server/tools.ts), architecture diagram, npm test
Under the hood: Hono on Node 22, React 19, OpenRouter tool calling, PayPal Invoicing v2 and Orders v2. An offline parser and a mock PayPal mean anyone can run it, and the test suite passes.
